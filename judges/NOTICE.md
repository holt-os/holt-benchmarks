# Third-party grading prompts

These files are copied unchanged so the grading can be checked. They keep their original licences.

- `evaluate_qa_official.py`: from [xiaowu0162/LongMemEval](https://github.com/xiaowu0162/LongMemEval) (MIT).
- `beam_prompts.py`, `locomo_prompts.py`: from [mem0ai/memory-benchmarks](https://github.com/mem0ai/memory-benchmarks) (Apache 2.0). The BEAM nugget judge is used from here. The LoCoMo prompt in this file is NOT the one used for Holt's score; it is kept for comparison.
- `locomo_judge_mem0paper.txt`: the LLM-as-judge prompt from Appendix A of the Mem0 paper, arXiv:2504.19413. This is the LoCoMo grader used for Holt's score.
